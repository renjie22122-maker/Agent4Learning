# runtime-5 验证记录

2026-09-28：更新 8800 服务，保留原有会话日志。不是与 Codex 或 DeepSeek Harness 等价的声明。

## 已实现

- 对话 Markdown 安全渲染，支持标题、列表、表格和代码；不直接执行模型输出的 HTML，不自动加载远程图片。
- 持久化上下文恢复，运行中追加消息，不同工作区并行主任务；同一工作区拒绝同时写入。
- SSE 文本与工具参数拼接、取消正在读取的响应；不执行半截工具参数。页面当前按周期刷新，不是逐 token WebSocket 推送。
- 子任务依赖、验收要求、显式重试和合并前差异检查；验收要求目前是提示词约束，不是通用机器验收器。
- Skill 目录、SKILL.md、ZIP 导入、启停、按需读取、步骤边界更新。参见 [技能说明](SKILLS.md)。
- 声明式插件依赖与已有工具别名；不自动加载任意 Python 插件代码。
- 宿主命令一次审批，绑定命令、会话及工作区，30 分钟有效；仅宿主页面可以批准。审批不是对命令引用文件内容的快照担保。
- Git 差异读取与从已有提交创建独立 worktree。不会自动复制未提交修改，也没有远程 PR 全流程集成。
- 独立隐藏浏览器，可预览工作区 HTML、读取、点击、填写和截图。每个远程 GET 通过域名和地址校验代理，POST、WebSocket 被拒绝。该工具不操作个人登录浏览器。
- 公开搜索工具使用 Bing RSS，需要授权搜索域名；结果目标网页仍需单独授权。未完成真实公网搜索质量验证。
- 知识库可选模型同义查询扩展；图片可发送至已配置模型分析，工具说明明确标注。它不是向量索引，图像模型输出也不是已验证事实。
- DOCX 内嵌图片与扫描 PDF 的内嵌图片尝试本机 OCR；不承诺所有 PDF 页面渲染与版式都支持。

## 环境与限制

本机浏览器配置位于受保护的 `.agent-runtime/browser-policy.json`，复用已安装的 Node Playwright 和 Edge；移到其他机器需要重新配置。Python Playwright 后端是另一种可选安装方式。Markdown 渲染使用 markdown-it-py。

Windows 当前采用原生文件隔离、宿主网络模式；严格离线预检失败时拒绝命令。尚无完整浏览器登录会话、向量检索、远程插件市场、跨机器任务迁移及通用可复现的长期任务质量评测。Skill 脚本和依赖需要按任务权限单独处理。
