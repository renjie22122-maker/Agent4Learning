# 知识库范围

普通对话默认仅启用本会话资料；项目对话默认启用本会话资料和项目知识库。
公共知识库默认关闭，用户从输入框旁的知识库入口主动勾选后才能检索。
可以关闭所有知识库。取消启用不会删除文档或已经进入聊天历史的引用。

管理页的导入、搜索、撤销、向量索引和原件链接均带 session / scope，
由宿主解析成存储目录，不接受客户端指定数据库路径。未知会话拒绝请求，
不会悄悄回退到全局当前工作区。没有会话时可管理当前项目库或公共库，
但不能修改任何会话的检索选择。

既有项目库沿用主工作区路径对应的存储，不移动或复制旧文档。
同一主目录绑定的多个项目仍共享项目库；多文件夹项目以主目录作为库标识。
普通对话沿用该会话独立产物目录对应的旧库。

工具仅遍历已启用的库，并返回范围和带范围的分块引用。
各库内部仍使用现有关键词/向量混合检索，跨库结果按库内排名交错合并，
不直接比较不同索引的 BM25 或向量分数。该合并策略尚未做大样本相关性评测。

子任务继承父任务的选择；独立验收为每个启用的库建立 SQLite 快照。
快照保存分块，不复制可下载原件或重建向量索引，缺向量索引时明确降级。
运行中的主任务不允许修改选择。修改范围使旧验收失效；不会清除模型历史中已读资料。

验证：`python -m unittest tools.test_knowledge_scopes -v`。
测试覆盖隔离、共享、显式启用、全部关闭、错误会话、稳定快照、运行中拒绝修改，
以及真实 HTTP 表单的范围保持与 CSRF 拒绝。这些是功能测试，不代表真实模型的回答质量评测。
