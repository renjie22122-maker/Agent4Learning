# Runtime 12：项目文件夹与网页访问

项目入口支持粘贴完整路径（每行一个）、Windows 原生多选文件夹窗口，以及网页目录浏览。最多关联 16 个互不包含的文件夹，首个为主文件夹；内部别名自动生成。项目卡片可以新建对话或修改设置。已有对话仍使用创建时的目录快照，不随项目配置变化扩大读写范围。

网页访问设置提供三种模式：允许公开网页、仅指定网站、关闭网页访问。保存后影响所有会话的后续网页及浏览器请求，无需重启。旧配置保留为仅指定网站模式；公开模式需要用户选择。网站输入支持完整 HTTP(S) URL 和批量域名，自动提取主机名；移除列表项不会切换模式。

公开模式仍校验 DNS 结果，拒绝内网、回环、保留地址，固定已校验地址建连，每次重定向重新检查。设置不改变 shell 的网络权限。网页内容仍作为不可信外部输入。

验证：46 项相关 Python 测试；Edge DOM 测试覆盖多文件夹选择响应、手动路径、保存参数和三个网络模式。原生 Windows COM 选择器已编译；自动测试不会弹出交互窗口，其实际鼠标多选尚需用户操作验证。
