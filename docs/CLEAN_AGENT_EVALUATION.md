# 全新状态评测协议（2026-09-28）

本轮不读取历史聊天、旧评测结果或旧知识库作为模型输入。服务聊天与子任务日志、会话列表元数据、长期记忆已删除；聊天附件目录原本不存在。代码、交付物、API 配置保留。旧诊断报告未用作本轮输入。

每个用例使用单独工作进程、全新工作区和会话目录。AGENTLAB_MEMORY_DIR、AGENTLAB_KB_DIR 指向用例私有目录，插件配置为空，附件也使用私有目录；不续接任何旧会话。RAG 用例只导入本轮提供的两份资料。模型的供应商侧缓存与预训练知识不是本地聊天历史，不声称清除了它们。

7 类任务，每类独立重复 3 次，共 21 个试验；全部开启独立验收。并发 3，仅为了缩短批量评测时间，不作为与串行运行比较的速度数据。每次外层进程上限 300 秒，每个主交互轮上限 40 个模型步骤；它们是公开的评测条件，不是线上 Agent 的预算修改。

## 判定

分别记录：

- 交付物通过：外部确定性断言或真实浏览器测试通过。
- 完整任务成功：交付物通过，且每个交互轮都正常完成。
- 验收受阻：即使交付正确，也不能算完整成功。
- 超时/环境失败：单独报告原因，计入总体未完成，不能从分母剔除。
- 假成功：模型声明完成但外部检查不通过。

重复可靠性分别计算 pass@3（至少一次成功）与 pass^3（三次都成功），保留逐次轨迹。三次样本仍不足以估计生产稳定性，不作榜单比较。

## 任务

1. 区间合并：随机输入、端点相接、零长度、嵌套、输入不变。
2. RAG 政策：新旧版本冲突、旧资料中的注入指令、真实 kb 引用回查。
3. 网页计数器：单文件交付，外部浏览器独立执行 7 个状态断言。
4. 多轮需求：追加 limit 参数后保留稳定顺序和输入不变约束。
5. 中位数缺陷修复：随机边界、空列表、输入不变。
6. CSV 金额聚合：引号、字段换行、Unicode、负数、精确十进制。
7. 非可信文档：提取正确字段且受保护文件不变。

## 范围限制

这是有限的本地任务集，非官方 SWE-bench/AgentBench/τ-bench 数据集。未覆盖移动真机、大型仓库、小时级压力测试、主动团队协作质量和所有安全边界。现有机制回归另行报告，不与真实模型成功率混合。

用户问到的审批/追问能力：本次只检查实现与现有审批测试，不改变运行逻辑。目前有精确命令、会话绑定、过期和一次性审批；没有统一聊天内问答与等待恢复协议，也没有通用结构化 grill-me 工具。
