# 本地混合检索

当前增加真正的 embedding：官方 `BAAI/bge-small-zh-v1.5`，版本固定为 `7999e1d3359715c523056ef9478215996d62a620`，512 维归一化 CLS 向量。本机 CPU 执行，只加载本地 safetensors，不执行模型仓库代码，不上传文档，也不占用 DeepSeek 聊天 API。

模型说明：https://huggingface.co/BAAI/bge-small-zh-v1.5

## 数据流

1. 现有格式提取器提取原文，保留文件、位置与 SHA-256；文本分块约 1000 字符、重叠 150 字符。
2. embedding 使用 tokenizer 的重叠窗口处理超长分块，避免只编码头部。每批至多 8 个源分块，推理子批最多 16 个窗口。
3. SQLite 保存分块 ID、模型版本、窗口、维度和 float32 向量。增量补建跳过已索引分块。
4. 关键词召回与余弦向量召回通过 RRF 融合，返回原始分块引用及相邻分块线索。没有向量覆盖的内容仍参与关键词召回。
5. 查询只使用当前知识库和 active 文档。撤销、旧版本不会通过向量查询重新出现。切换模型版本后旧向量不混用。

## 使用

本地模型通过 `.agent-runtime/rag.json` 配置，公开克隆不附带本机配置或模型权重。配置完成后，知识库页面显示向量覆盖数，新导入自动补建；旧资料点击“补建当前知识库向量索引”。每个库分别建索引；会话、项目、公共范围见 [知识库范围](KNOWLEDGE-SCOPES.md)。

也可运行：

```powershell
python -m agentplat.knowledge_cli --workspace D:\你的项目 reindex
python -m agentplat.knowledge_cli --workspace D:\你的项目 index-status
```

模型未准备好、索引缺失或查询出错时明确返回降级提示，继续关键词检索，不伪称完成语义检索。配置 `enabled=false` 或进程环境变量 `AGENTLAB_VECTOR_RAG=0` 可关闭。

## 检索实验

运行 `python tools/evaluate_vector_rag.py 新的输出目录`。固定 12 个中文同义改写问题与 1000 条干扰记录，总计 1012 个分块，不使用 LLM 给自己打分。

首次实测：建索引 18.52 秒；关键词 Recall@5=0.667、MRR@5=0.396；混合检索 Recall@5=0.833、MRR@5=0.517。原始报告在 `.diagnostics/vector-rag-1012/report.json`，失败问题也保留在报告中。

这只是合成回归，干扰内容种类有限；不能代表真实企业库或回答准确率。应继续收集真实问题与相关原文标注，并测无答案问题、版本冲突、表格与 OCR、跨章节组合、多语言问题。

## 已知边界

- 小库使用分批扫描的精确 flat 索引；`ann_backend=auto`、`ann_min_vectors=50000` 时，建索引流程会为达到阈值的库尝试建立经召回校准的 HNSW。ANN 不可用时回退并报告原因。实现和专项历史验证见 [runtime-20](RUNTIME20_UPGRADE.md)。不是分布式数据库，也不代表已证明百万级真实问答质量。
- 尚未加入交叉编码器重排序、复杂表格结构重建与标题感知分块。默认 top_k=5 可由工具调用调至 20，不能靠盲目扩大 top_k 保证质量。
- 中文小模型并不保证所有领域与语言的语义质量。相似度高不代表内容支持答案；模型必须检查原文，信息不足时如实说明。
- 独立验收使用宿主一致性知识库快照及只读来源工具。至少真实读取原始分块是必要条件，仍不等于已自动证明所有答案事实。
