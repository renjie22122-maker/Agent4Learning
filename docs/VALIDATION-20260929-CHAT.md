# 普通对话与恢复验证（2026-09-29）

本轮修复针对普通对话隔离、快捷继续、自然语言收尾、API 连接自检和会话导航。不是所有 Agent 能力的全面验收。

## 已验证的行为

- 新普通对话使用 `.chat-storage/<session>/files` 保存独立产物，不绑定公共 `workspace` 或项目目录；历史对话不自动迁移。
- 普通对话命令、宿主命令审批及项目委派被宿主工具守卫阻止，相应工具也不再发送给模型。读取附件和生成会话内文档仍可用。
- 无文件变化、无待验收的普通问答允许自然语言收尾。项目代码任务继续使用原有验证规则。
- 文本产物独立验收支持 `check_file_text` 精确断言（UTF-8、包含空白和换行），绑定当前内容摘要；它不替代代码行为测试。错误预期与文件变化均有负对照。
- 输入框附近可以继续未完成任务；读取持久日志，未知工具结果/损坏日志阻止快捷启动，重复点击不重复追加要求。
- 执行步骤默认收起，详情保留。首次进入定位最新消息；顶部轮次菜单可跳到用户消息开头或返回最新消息。

## 真实 API 结果

使用用户已有 DeepSeek 配置及独立测试目录，未把历史会话作为测试输入。

| 测试 | 结果 | 私有报告 |
| --- | --- | --- |
| 中断后重建服务对象、通过 HTTP 续跑；文件不重写；跨会话读取被拒；未知操作不续跑 | 9/9 检查通过 | `.diagnostics/general-resume-live-v4/report.json` |
| 普通问答“你有工作区吗” | 1 次模型调用、0 次工具调用，正常完成 | `.diagnostics/general-answer-live-v1/report.json` |

恢复测试重建了服务对象，并非对 Windows 进程施加断电。模型自选工具和独立验收均使用真实 API；未知结果拦截为明确注入的宿主故障场景，不消耗新模型请求。

## 失败及修复过程（保留，不算通过）

- v1：受限执行环境网络拒绝，未完成真实 API 流程。
- v2：文档任务被命令证据要求阻塞，触发测试专用 300 秒超时。
- v3：产物正确且未重复写入，但独立验收要求命令/浏览器证据，未正常收尾。
- v4：增加独立文本断言后完整通过。300 秒与 30 步是本专项测试参数，不是产品默认硬预算。
- 服务继承受限代理 `127.0.0.1:9` 导致 WinError 10061；改在正常宿主环境启动，启动器检测该已知无效环境并明确拒绝启动，不删除或改写用户代理配置。
- 连接测试 JSON 模式缺少 JSON 提示，真实服务返回 400；已补正提示并实测。
