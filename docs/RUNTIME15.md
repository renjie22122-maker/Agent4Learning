# Runtime 15：登录体验与故障恢复

- 本机服务启动复用同端口的有效凭据，登录 Cookie 保留 30 天。未登录用户看到引导页；不会向匿名页面泄露登录 token，也不允许仅凭本机网络访问控制服务。清除浏览器数据或更换浏览器仍需通过桌面入口登录。
- 凭据文件采用临时文件替换写入，避免启动时半写入。
- 模型请求收到可重试的 429/503 时，在 1 秒、3 秒后最多重试两次。每次请求单独计数并记录重试事件；取消可以中断等待。401、400、结果不明的超时不自动重试，不重放工具操作。请求未返回 usage 时仍不能保证账目完整。
- 同一工具、相同参数、相同错误在相同文件状态下累计六次失败，即使中间交替调用其他工具，也停止无效重试。文件变化或该调用成功后允许重新尝试。这不是通用语义性无进展检测。
- 子任务记录请求开始与结束时间，团队页显示当前模型请求及实际等待秒数，不再只靠 token 数猜是否卡住。

仍未提供：跨进程自动恢复未知副作用、自动启动新服务器进程、完整的长期任务语义进展证明。中断记录和文件会保留，需根据状态继续；本轮没有新增固定总 token 上限。
