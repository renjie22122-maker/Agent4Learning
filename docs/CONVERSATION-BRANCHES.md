# 回复操作与文件版本分支

每条已保存的回复提供复制 Markdown、赞/踩、反馈原因和“从这里分支”。代码块有独立复制按钮。会话菜单提供复制全部对话和 Markdown 导出。评分与原因只存于本机，可修改或撤销，不发送给模型供应商。

分支继承至所选轮次的模型上下文，不继承后续消息，不重放工具调用，也不会自动发起模型请求。分支仍可从更早的一轮继续分支。

文件有三种方式：

- **所选轮次快照**：新完成的轮次保存宿主文件快照；创建分支时校验摘要，再复制到独立目录。
- **当前文件副本**：旧轮次没有快照时可选择，明确不代表历史文件版本。
- **共享当前项目文件**：仅项目对话可显式选择；修改会影响原项目，不具有版本隔离。

普通对话的独立副本保存在新会话的私有文件目录，项目分支可复制多个工作区文件夹。快照不包含 Git 元数据、依赖目录和运行缓存。附件服务绑定、记忆与知识库不通过此功能复制；不能把历史消息中的附件引用视作已迁移的附件。

当前实现是文件快照和独立目录，不创建 Git commit/branch，不提供差异比较、合并、冲突解决或原地回滚。不能将其称作完整 Git 版本管理。

单份快照限制为 128 MiB、10000 个文件。超限、链接、文件变化或读写错误会标记“快照不可用”，仍保留本轮对话；界面显示原因。快照目前未去重，也没有自动过期清理，因此长期使用会增加磁盘占用。
