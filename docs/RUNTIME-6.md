## 容量与费用

上下文窗口默认自动：优先采用当前 API `/models` 的 `context_window`、`context_length` 或 `max_context_length`；按 API 地址和凭据分别缓存。切换模型匹配对应模型 ID，切换端点不会复用旧端点的容量。已确认的官方 DeepSeek 模型有明确回退配置，其余未知模型回退 64K 并标明容量未知。设置页的“上下文窗口”填 0 自动，正数手动覆盖。任务显式窗口仍优先，用于教学实验。

本机 `deepseek-flash` 实测接口返回 **1,048,576**。80% 压缩阈值随容量更新。上下文内容占用仍是本地估算，不是 API 账单 token 数。正在进行的请求不改写配置，新任务使用更新后的模型配置。

对话显示 API 实测输入、输出、缓存命中用量，缺 usage 时标明估算；本次流式请求尚未收到 usage 时显示待结算。缓存 token 是输入子集，不重复计算。主流程、摘要、辅助模型及子任务分项记账。旧日志缺少用量细项时不伪造历史记录。

官方 DeepSeek 价格从 [价格页](https://api-docs.deepseek.com/quick_start/pricing/)获取，按小时缓存，在启动、创建任务或下一轮对话时按需更新；显示来源和获取时间。解析失败保留标注日期的快照。其他供应商暂使用设置页的回退单价，不声称已自动发现价格。

官方价格有峰谷与中国公共假日例外。本机尚未接入权威节假日日历，工作日峰时显示半价至峰价的范围；非峰时采用低价。计算金额不是供应商最终扣款，折扣、补贴及未知中断用量仍需以账单为准。

## 流式与权限

`/agent` 使用 EventSource/SSE 推送发生变化的输出及账目，服务器约 100ms 合并一次更新；不再每四秒请求整页。输入框不被替换。模型首字延迟仍由供应商决定，尤其推理阶段没有正文时，不承诺一秒出字。

“执行权限模式”可选只读、自动、完全访问（宿主命令）。只读限制工具和写入；自动使用现有执行后端与逐次审批；完全访问由宿主表单显式选择后允许本机命令。运行中在下一步骤生效，不会撤销已运行的操作；网页抓取仍需域名授权。默认自动，不默认放权。

## 独立验收与子任务

主 Agent 已有 spawn/wait/message/cancel/retry 等子任务工具；深度仍为 1，子任务不能继续派生。

网页主任务产生改动并通过自身证据检查后，完成闸门自动启动独立验收者：独立上下文、工作区副本，只提供用户要求，不提供作者总结。验收者编写/执行检查，不能修复原始交付文件；父级要求结构化 verdict、实际运行证据及不变的父工作区版本。失败、超预算或格式错误都不视为通过。同模型独立执行减少自评偏差，不保证发现所有缺陷。

真实负例已完成：验收者检查有缺陷的 median.py，发现偶数结果错误、空列表异常类型错误、修改输入列表，并给出 fail。早期试跑耗尽预算；最终使用限定工具、低推理强度和“找到确定反例即报告”，避免无限扩充验证任务。

## 故障修复与验证

- 异常退出也推进轮次高水位、闭合当前步骤；下一轮根据实际日志重新确定编号。异常后追问及再次恢复回归通过。
- 空正文或截断响应不再用 reasoning_content 充当正式摘要。摘要要求段落结构；切分时保留完整工具调用批次。
- 真实摘要例：20,518 → 296 本地估算 tokens；原任务、补充约束、关键事实、近期消息、调用配对和续答检查通过。此合成样例不代表一般长任务压缩质量。
- test_chat 接受诚实的 unverified 终止；test_support 可直接运行；非提权的 Windows 原生集成测试显示 skip，不冒充通过。
- 24 个离线测试套通过，35/35 默认实验通过。新增实验 38（压缩协议）、39（缓存计费）。HTTP SSE 已验证任务结束前收到多段正文。

主要复现命令：`python tools/test_offline.py`、`python verify.py`。真实模型测试：`tools/demo_compaction_live.py`、`tools/check_independent_review_live.py`，会消耗配置的 API 用量。
