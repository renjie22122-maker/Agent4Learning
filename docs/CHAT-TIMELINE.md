# 对话时间线与交互记录

授权与问答按创建时间插入所在轮次的工作过程，追加提示按接收时间穿插；不再将所有记录统一堆在整段对话底部。已完成交互默认折叠，标题保留命令/问题摘要；待回答交互展开。运行输出按交互边界分段，后续步骤位于对应消息之后。

记录新步骤和流式文本开始时间，并随 ui/turn 持久化。历史轮次从 run/started、assistant/message、steering/queued 事件恢复已有时间；旧日志缺少精确步骤时间时只能恢复消息层顺序，不伪造逐步骤时间。无匹配时间范围的旧交互保留为兜底记录，不丢弃。

SSE 更新移动已有交互 DOM 到稳定 question-id 插槽，保留输入草稿、焦点和折叠状态；步骤展开状态按稳定标识恢复。用户已滚离底部时不强制追随输出。

验证：14 项 Python 回归通过；隔离 Edge 页面使用生产 LIVE_JS/HUMAN_JS 和模拟 SSE 数据验证 9 项浏览器检查：默认折叠、等待展开、原位插入、展开保留、草稿保留、焦点保留、无重复、追加提示顺序、再次收起。浏览器测试没有调用真实 LLM。结果在 .diagnostics/chat-timeline-browser.json，截图 chat-timeline.png。
