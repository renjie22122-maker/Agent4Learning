# Runtime 10：会话右键菜单

在侧栏会话上右键，或点击「⋯」，可使用：

- 在新标签页打开、复制本机对话链接、导出 Markdown。
- 重命名、置顶/取消置顶、标记已读/未读。
- 移动到项目或普通对话（仅分类，不改变已有文件访问范围）。
- 归档/取消归档、移入回收站/恢复。

侧栏底部提供活动会话、已归档、回收站入口。置顶作用于所属分类内。
删除是软删除，保留日志、原工作区和记忆来源；不会删除项目文件。
运行中的任务需先停止才能移入回收站；回收站里的会话需恢复后才允许续跑。
归档不停止运行任务。已有记忆可在长期记忆页面单独撤销。

状态存放在宿主 `.agent-runtime/conversations.json`，原子替换保存。
所有修改需要浏览器会话认证与表单 token，不通过模型工具开放。
菜单操作只更新侧栏，保留会话阅读位置和输入草稿。

测试：`python -m unittest tools.test_conversations`，以及浏览器回归
`tools/test_chat_browser.cjs` 中的右键重命名、更多按钮和草稿保留检查。

工具与设置固定在侧栏左上方，位于标题下方，不随会话列表滚动；窄屏保留顶栏设置入口。菜单按知识与能力、当前会话、授权与配置分组。
