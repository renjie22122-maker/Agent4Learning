# Runtime 14：验收收敛与多轮交付范围

本轮修复见 [完整评估](AGENT_ASSESSMENT_RUNTIME14.md)。主要变化：主模型在独立验收期间挂起等待；普通 wait 返回实际耗时及简短结果；验收支持受阻结论、真实浏览器断言与进度；取消显示为中止；后续只读请求不因历史修改自动重新验收。

验证记录：

- 90 项 unittest 回归通过。
- 41 个教学实验完成验证。lab-45 初次因指标名触发方向分类错误而失败，改为 missing_review_outcomes 后与 lab-44 一起复验通过。
- 真实 API：网页按钮交互验收通过；有缺陷的中位数实现被拒绝；缺少命令执行权限时返回 blocked。
- 真实浏览器：本地预览、填写、点击、中文文本断言、截图及 file URL 拒绝通过。
- 网页正例初次出现结论协议歧义，明确 pass 的 findings 必须为空、正面观察写入 tests 后重测通过。

新增教学实验：lab-44-review-wait、lab-45-review-blocked。预算仍按用户配置，不新增默认固定 token 上限。

剩余限制：后台浏览器不是用户可见预览入口；等待修复不能证明模型永远不会扩大验收范围；成功命令或单个浏览器断言也不能代替逐项需求覆盖。
